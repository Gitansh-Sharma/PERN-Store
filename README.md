# PERN Store

A full-stack e-commerce web application built using the **PERN stack** — PostgreSQL, Express.js, React.js, and Node.js.

The application provides a modern shopping experience with product browsing, authentication, cart management, and order functionality.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Styling:** Tailwind CSS
- **Payments:** Stripe
- **API:** REST

## Project Structure

```text
PERN-Store/
├── client/     # React frontend
├── server/     # Express/Node.js backend
├── Deployment/ # Deployment configuration
└── ...
```

## Purpose

This project demonstrates the development of a full-stack e-commerce application with a React frontend, REST API backend, and PostgreSQL database.
